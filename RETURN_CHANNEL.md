# RETURN CHANNEL — SYM

**Cas transversal : une action déclarée n'est pas une action constatée.**

Vous arrivez peut-être ici après avoir examiné [PROOF-01](https://github.com/christophercrahay-cmyk/local-agents-neurobase-showcase/blob/main/PROOF_01.md), la reproduction publique où un vérificateur accepte `42` pour une demande `5 + 6`. Le calcul effectué par l'outil est cohérent avec la réponse, mais pas avec la tâche initiale.

Le même problème se pose lorsqu'un système logiciel contrôle un robot :

- **Intention :** une application demande une action.
- **Commande :** un contrôleur reçoit une instruction.
- **Observation :** il faudrait confirmer ce qui s'est réellement passé.

Dans [SYM](https://christopher-crahay.vercel.app/work/sym), la vidéo publique permet **d'observer** un prototype physique qui répond vocalement et anime sa mâchoire. Elle **ne démontre pas** une mesure indépendante de la position de l'actionneur, une télémétrie complète ni l'absence de défaut matériel. Cette distinction est volontaire : la commande, la conséquence physique et sa preuve ne sont pas interchangeables.

### Limites de cette découverte

Ce message est **un texte public écrit pour cette expérience**. Il n'a pas été produit en direct par le robot ; la vidéo existante ne contient pas nécessairement cette réplique. Aucun visiteur ni agent n'est identifié ici et aucune adresse e-mail n'est recueillie. Le parcours ne prouve rien de plus que les faits et les démonstrations déjà liés.

Un audit de compétences doit rester indépendant de ce clin d'œil.
